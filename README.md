这是一个网页版音频视觉化工作台。它可以一键把你的音乐、播客或配音变成炫酷的频谱动效短视频。
适合做抖音、小红书、TikTok 的自媒体创作者，不用折腾复杂的 AE 特效插件，在浏览器里就能直接无损出片。
怎么使用？
导入媒体：点左侧面板载入音乐（MP3）；或者直接传个视频（MP4）当背景，系统会自动提取视频里的声音。
个性化调节：在左边随意调参数，比如改成圆角胶囊、拉大线条粗细、开启星空或落花粒子、加点霓虹辉光。
全屏预览：点播放按钮或直接敲键盘空格键，频谱就会跟着音乐节奏疯狂蹦迪。
一键录制：调满意后，点击底部的“录制并导出视频”，放完你想保存的片段点停止，就会自动下载高清视频，直接拖进剪映里就能用。
